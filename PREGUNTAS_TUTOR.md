# Preguntas para el Tutor - ClimateNews AI

## Preguntas sobre implementación del proyecto:

1. **Web Scraping de Noticias**
   - ¿Qué APIs de noticias gratuitas recomiendan para obtener noticias sobre cambio climático en tiempo real?
   - ¿Cómo manejar correctamente los rate limits y evitar bloqueos al hacer scraping de múltiples fuentes?
   - ¿Es mejor usar APIs específicas de noticias o hacer scraping directo de sitios web?

2. **Procesamiento de Lenguaje Natural (NLP)**
   - ¿Qué biblioteca es mejor para clasificar el impacto ambiental de una noticia: NLTK o SpaCy?
   - ¿Cómo entrenar un modelo simple para clasificar noticias por nivel de impacto (alto/medio/bajo)?
   - ¿Cómo extraer keywords relevantes sobre el clima de un texto de manera efectiva?

3. **Visualización de Datos**
   - ¿Cómo integrar Plotly con Flask de manera eficiente para gráficos interactivos?
   - ¿Cuál es la mejor forma de generar nubes de palabras dinámicas en tiempo real?

4. **Base de Datos**
   - ¿SQLite es suficiente para este proyecto o recomiendan usar PostgreSQL?
   - ¿Cómo estructurar mejor la tabla de noticias para permitir búsquedas eficientes por fecha, impacto y keywords?

5. **Despliegue**
   - ¿Qué plataforma recomiendan para desplegar una aplicación Flask con estas características?
   - ¿Cómo manejar la actualización automática de noticias (cron jobs, background tasks)?

6. **Mejoras Adicionales**
   - ¿Cómo implementar un sistema de alertas para eventos climáticos importantes?
   - ¿Es posible integrar un generador de resúmenes automáticos con las bibliotecas disponibles?
